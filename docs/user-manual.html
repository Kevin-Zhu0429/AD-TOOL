1　手册说明

1.1　本手册讲什么

CYES 广告工作台是公司内网的一个网页工具，登录后一共有几页功能。本手册只讲其中三页：

模块解决什么问题产出
自动广告把「开几十条自动广告」这件事从手工拼表变成填表单一份可直接上传亚马逊后台的 xlsx 批量表
否定词库A–E 五类否定词集中维护，谁维护、覆盖哪些站点有明确分工开广告时自动写进每一条活动的否定行
SKU 库把自己负责的 SKU 和库存存起来，开广告时不用再翻 Excel「投放 SKU」框里一键填入

导航栏里可能还会看到「手动广告」「广告优化」「账号管理」，这三页不在本手册范围内：前两页是试用功能、需要超级管理员单独开权限，账号管理只有超级管理员可见。

2　访问与登录

工具部署在公司内网的一台电脑上，用浏览器打开就能用，不需要安装任何客户端。

2.1　网址怎么来

网址的形式是：

http://<工具机的内网 IP>:8080
例：http://192.168.1.50:8080
  • 端口默认是 8080，前端页面和接口都由这一个地址提供。
  • 准确的 IP 由管理员在部署时确定并发给大家，请以管理员群里发的那条链接为准，建议直接加到浏览器书签。
  • 只能在公司内网访问，在家或用手机流量打不开是正常的。
  • 浏览器推荐 Chrome 或 Edge，最新版本即可；不要用 IE。
如果打不开 先确认三件事：① 电脑连的是公司网络；② 网址前缀是 http:// 而不是 https://； ③ 工具机是否开着（这个工具跑在一台内网电脑上，那台机器关机或重启后没启动服务，所有人都打不开）。三条都没问题再找管理员。

拍什么：整个浏览器窗口，地址栏里的实际内网网址要清晰可见（IP 可按公司要求决定是否打码），页面是「广告工作台」登录卡片。这张图用来告诉新同事「从哪进」。

2.2　账号怎么来

  • 账号不能自助注册，由超级管理员在「账号管理」里开通，登录页底部也写着「仅限公司内网 · 账号由管理员开通」。
  • 开通时管理员会一并设定：用户名、姓名、初始密码、角色、负责的站点。
  • 角色分三种：超级管理员（owner）、国家管理员（admin）、运营（operator）。后两者权限目前完全一样，只是职级名称不同。
  • 商品部同事还会额外勾上「商品部维护权」，才能编辑 B/C/D/E 四类词库。

2.3　登录步骤

  1. 浏览器打开网址，看到「广告工作台 · 批量开发 · 否定词库」的登录卡片。
  2. 填用户名（管理员给的那个英文名，不是中文姓名）。
  3. 填密码。
  4. 点「登录」。按钮显示「登录中…」时不要重复点击。
  5. 成功后直接进入首页；失败会在按钮上方显示红色提示。
小技巧 登录卡片右上角有个太阳 / 月亮图标，可以切换浅色 / 深色主题，登录前后都能切，纯属个人喜好，不影响功能。

2.5　切换站点

站点（ES / DE / FR / IT / UK / US / CA / AU）决定了你在自动广告和否定词库页看到和写入的是哪一份数据。

  • 在右上角下拉框里选，选完当前页面会自动重新加载对应站点的词库。
  • 只负责一个站点的账号没有下拉框，直接显示站点名。
  • 需要负责更多站点，找超级管理员在「账号管理」里勾。改完对方刷新一下页面就生效，不用重新登录。
开广告前先看一眼站点 自动广告页页头会写「开设广告　ES 站」。站点选错，带进去的否定词库和挑出来的 SKU 都会是别的站点的，生成的表也就废了。

2.6　改姓名和密码

头像菜单 → 「个人资料」。这一页可以做两件事：

  • 改姓名：改的是显示名（同事在词库「添加人」一栏看到的就是它）。20 字以内。
  • 改密码：要填原密码 + 新密码 + 确认新密码。新密码至少 6 位，且不能和原密码相同。

角色和负责站点自己改不了，由超级管理员分配。忘了原密码，找超级管理员重置。

拍什么：整页，包含账号信息卡片和「修改密码」表单三个输入框。

2.7　退出与登录失效

  • 正常退出：头像菜单 → 「退出登录」。公用电脑上用完请务必退出。
  • 登录状态保持 12 小时，超时后再操作会提示未登录，重新登录即可。
  • 页面数据是实时的：管理员改了你的站点、角色或权限，你刷新一下页面就生效。
未保存的内容会丢 自动广告页填的任务内容只存在浏览器里，没有草稿保存。刷新页面、切换站点、退出登录、关闭标签页都会清空正在填的任务。 内容多的时候，建议先把 SKU、否定词这些长文本在记事本或 Excel 里留一份。

换句话说：SKU 库负责「投什么」，否定词库负责「不投什么」，自动广告页把两者拼成亚马逊要的批量表。 三个模块可以完全独立使用——SKU 也可以手打、否定词也可以临时粘贴——但用好前两个库，开广告这一步就只剩点几下。

3.2　建议的使用顺序

  1. 第一次用：先去「SKU 库」把自己负责的 SKU 导进去（第 4 章）。这是一次性工作，之后只需要月度更新库存。
  2. 开广告前：去「否定词库」确认本站点的五类库是不是最新的，特别是 D 类（第 5 章）。词库是共用的，一般由商品部更新，你只要确认一眼。
  3. 开广告：进「自动广告」页，一个任务一个任务地填，右侧预览确认没有「待处理」，生成总表下载（第 6 章）。
  4. 上传：把下载的 xlsx 拿到亚马逊后台走批量上传。

4　SKU 库

导航栏 →「SKU 库」。页面标题写的是「我的 SKU 库」——注意这个「我的」。

4.1　这是什么、给谁用

  • 每个账号一份自己的库，别人看不到。你导进去的 SKU 只有你自己（和超级管理员的只读视图）能看到。
  • 所以大家只传自己负责的品牌，不用担心和同事的数据打架，也不用商量谁来传。
  • 库里的数据只有一个用途：开广告时在「投放 SKU」那里点「从 SKU 库选」，按站点 + 型号筛出来勾选填入。
  • 库里的库存数字不会自动同步后台，是你自己传进来的快照，用来判断「这个 SKU 还有没有货、值不值得投」。
截图 05SKU 库页面全貌
拍什么：整页。要包含右上角四个按钮（下载模板 / 导出 Excel / 导入 Excel / 整表替换）、左边「批量添加」和「模板列」两张卡片、右边带数据的表格。建议拍已经有几十行数据的状态，比空库更直观。

4.2　模板七列怎么填

列必填说明
国家必填站点码：ES / DE / FR / IT / UK / US / CA / AU。写「西班牙」「德国」这种中文名也认，写「ES 站」也认；认不出来的会报错
品牌选填自己负责的品牌，如 HP、Canon。挑 SKU 时可以按它筛
型号选填填 301 即可。查的时候 301 和 301XL 会归到一起；PG-545 输 545 也能查到
套组选填如 BK / 2BK / BKC / C，方便挑要投的那几个
SKU必填后台实际用的 SKU，一行一个，最长 120 字符
在库库存选填数字。挑 SKU 时会显示在后面
在途库存选填数字。在途 / 补货中的数量
两个数字列必须是数字 在库 / 在途填了「暂无」「待补」这种文字，那一行会被判为错误跳过，导入完会提示「N 行没通过」。不知道就留空，留空是允许的。

4.3　方式一：模板导入 Excel（推荐第一次用）

  1. 右上角点「下载模板」，得到 SKU库导入模板.xlsx。里面有两个工作表：SKU导入（表头 + 三行示例）和填写说明（每列必填与否、怎么填）。
  2. 在「SKU导入」表里，把三行示例删掉，填上自己的数据。表头那一行保留不动。
  3. 存盘，回到网页点「导入 Excel」，选中这个文件。
  4. 页面上会出现一条结果提示，例如「新增 128 行 · 更新 12 行」。
表头不一致也能认 系统会先按标准列名对，对不上再按关键词猜（「站点」认成国家、「机型」认成型号、「可售库存」认成在库、「seller sku」认成 SKU 等）。 实在一个都认不出来，就按列的先后顺序读——所以从别处导出的表，只要列顺序和模板一致，也能直接导。

4.4　方式二：从 Excel 复制粘贴

零星补几行时更快：在 Excel 里选中要传的数据区域（不含表头），Ctrl+C，粘到页面左边「批量添加」的大框里，点「写入我的库」。

  • 列的顺序必须是：国家 → 品牌 → 型号 → 套组 → SKU → 在库库存 → 在途库存。
  • 列之间是 Tab（从 Excel 复制出来天然就是 Tab），也认 ~ 和 |。
  • 不认逗号，也不认减号——因为 SKU 和型号本身就带 -。
  • 框下面会实时显示「N 行待添加」，可以先核对行数再点写入。

ES→HP→301→BKC→CY-ES-HP301XL-BKCL→120→300
ES→HP→302→2BK→CY-ES-HP302XL-2BK→0→500
DE→Canon→PG-545→BK→CY-DE-CA545XL-BK→80→

4.5　重复传会怎样、整表替换怎么用

同一个国家 + 同一个 SKU 再传一次 = 更新这一行（含库存），不会变成两条
不同国家的同一个 SKU = 两条独立的行，互不影响

所以月度更新库存的正确做法就是：把最新的表原样再导一次，系统自己会判断哪些是新增、哪些是更新。

「整表替换」用在另一种场景：这一批数据里出现过的那几个国家，先整个清空，再写入文件里的内容。

  • 只清「这批数据里出现过的国家」——传一份只有 ES 的表，不会动 DE 的数据。
  • 别人的库完全不受影响（本来也互相看不到）。
  • 点了会先弹确认框，写清楚要清哪几个国家、要写入多少行，看清楚再点确定。
  • 粘贴方式也有整表替换：批量添加框下面那个勾选框「先清空这批数据里出现的国家再写」。
整表替换会真的删掉旧行 用在「这个国家的 SKU 表我重新整理过了，以旧的为准」的场合。 如果只是补几个新 SKU、或者只想更新库存，用普通导入就够了，不要用整表替换。删掉的行没有回收站。

4.9　SKU 库注意事项

  • 国家一定要填对。国家决定了开 ES 站广告时这条 SKU 会不会被筛出来。国家填错，广告页那边就是「搜不到」。
  • 型号建议只填数字部分（301 而不是 HP 301XL 黑色）。系统按「去掉非数字字母、去掉结尾 XL、从第一个数字截到底」来比对，型号填得越干净，搜起来越准。
  • 库存是手工快照，不会自己更新。建议跟着月度节奏重新导一次，避免拿着上个月的库存判断投不投。
  • SKU 必须是后台真实存在的 SKU。这里不校验对错，写错了要等上传批量表被亚马逊拒了才知道。
  • 删除、整表替换都没有撤销。大批量操作前先「导出 Excel」留一份底。

  • E 原装竞品 ASIN——各市场的原装竞品 ASIN。数据格式还没定稿，先按 ASIN + 品牌 + 对应墨盒型号存着，开广告时默认不带。

5.5　录入：批量粘贴 / 导入 Excel / 整表替换

批量粘贴（适合零星补词）

  1. 先切到要写的那一类页签（切错类是最常见的错误）。
  2. 在左边「批量添加」框里粘贴内容：
    • 单列词库（A、B）：一行一个词。
    • 多列词库（C、D、E）：从 Excel 直接复制粘贴，列之间是 Tab。框里的占位文字会写明本类的列顺序。
  3. 需要整表更新就勾上「先清空这一类再写」。
  4. 点「写入 X 类」。结果会显示成「清掉旧的 M 行 · 新增 N 行 · K 行已存在跳过」。
D 类的逗号不是分隔符 D 类的墨盒型号本身就写成「575, 576」这种一格里两个型号的形式，所以逗号不当列分隔符，只有 Tab 才是。 直接从 Excel 复制粘贴就不会有问题；不要自己手动用逗号拼一行。

导入 Excel（适合整批更新）

  • 点「导入 Excel」选文件，支持 .xlsx / .xls / .csv，读第一个工作表。
  • 表头会自动识别，也认带前缀的写法（例如「欧洲墨盒型号」也能认成「墨盒型号」）。
  • 表头实在认不出来，就按列的先后顺序读——所以列顺序对了也能导。
  • 导入是追加：已存在的行会跳过，不会产生重复。

整表替换（月度整表更新用）

「整表替换」按钮选文件后会先弹确认框，写明「XX 的『某类』现有 N 行会被清空，换成文件里的 M 行」。确认后先清空这一类再写入。

整表替换影响整个区域 对 B / C / D 这类区域库来说，一次整表替换会同时改变整个区域所有站点看到的内容（欧洲 = 5 个站）。 这是商品部月度更新的标准动作，其他人不要随手点。替换前建议先「导出 Excel」留一份旧数据。

  • 搜索：右侧搜索框，所有列一起搜。
  • 筛选：品牌、打印机系列两个下拉（主要给 D 类用，数据里出现过一种以上时才出现）。
  • 删除：勾选行 → 右上角「删除选中 N」→ 确认。删了就没了。

开关作用

5.8　D 类的特殊用法

D 类和其他四类根本不同：它存的是在售的墨盒和打印机，不会整库当成否定词。它有两个用途：

用途一：系列广告的联动否定

开「系列广告」时选中要投的墨盒型号（比如 301），系统用 D 类反推该否掉什么：

  • 其余墨盒型号全否；「575, 576」这种一起卖的，选中一个，同组的另一个也留着不否。
  • 其余打印机型号全否；正在投的那个系列的打印机，一个都不会被否掉。
  • 同一个数字在别的系列里也出现过时（比如两个系列都有 2540），会自动写成「DeskJet 2540」这种带系列名的形式，不会误伤在投的机型。

具体操作在自动广告页，见 6.4。

用途二：当打印机型号库用

运营在词库页可以按品牌、打印机系列筛选和搜索 D 类，当成机型查询表用；开广告时还能从里面直接挑几个机型写进否定词（见 6.5）。

5.9　否定词库注意事项

  • 先确认站点和类别。页面跟着右上角站点走，写错站点 / 写错类别是最常见的失误。
  • 单个否定词不能超过 80 字符，超了导入时会被拒并提示。
  • ASIN 必须是标准格式（B0 开头共 10 位）。写成 asin="B0…" 也认，系统会自动存成纯 ASIN。
  • 改动立即生效，没有审核环节。区域库改一次，同区所有站点下次开广告都会带上新内容。
  • 删除和整表替换不可恢复，动手前先导出留底。
  • E 类默认不往广告里带（格式未定稿），需要时在自动广告页任务里手动勾。
  • 亚马逊每条活动的否定词上限一般是 1000 个。欧洲 D 类有一千多行，开系列广告时很容易顶到上限，页面会提示，处理办法见 6.4。

否定词超 1000 个怎么办 欧洲 D 类一千多行，墨盒 + 打印机一起否很容易超过亚马逊每条活动 1000 个否定词的上限，超了页面会在预览区提示。 处理办法：把「联动否定」切成只否墨盒型号（或只否打印机型号），或者把 SKU 拆成多个任务分批开。

6.5　区块 4：生成组合（决定开出多少条活动）

自动广告类型

亚马逊自动广告的四种投放方式，可多选：

Close 紧密
Loose 宽泛
Substitutes 同类
Complements 关联

每条活动里四种都会写进去，但只有你勾中的那一种是「已启用」并给出价，其余三种写成「已暂停」。勾几种，就会生成几倍的活动。

竞价方案

可多选，六个选项其实是三种策略 × 两种命名写法（中文 / 英文后缀）：

选项写进表里的竞价方案命名后缀
仅降低动态竞价 - 仅降低仅降低
提高和降低动态竞价 - 提高和降低提降
固定竞价固定竞价固定竞价
DOWN ONLY动态竞价 - 仅降低DOWN ONLY
DOWN UP动态竞价 - 提高和降低DOWN UP

只有「提高和降低 / DOWN UP」会打广告位系数 另外两种策略的系数一律按 ×1 算（详见 6.7 的出价公式）。

瀑布流 还是 组合

模式含义怎么填
瀑布流一条活动一个广告位 × 一个溢价档位勾选溢价位置 + 填溢价档位（逗号分隔）
组合一条活动多个广告位，各给各的溢价一行写一条活动，如 TOS:100 ROS:50

瀑布流下：

  • 溢价位置三个：TOS（搜索结果首页首位）、ROS（搜索结果其余位置）、PP（商品页面）。默认 TOS+ROS，旁边有「不加溢价 / TOS+ROS / 三个位置」三个快捷按钮。
  • 溢价档位默认「标准 10 档」：20,35,50,80,100,200,300,500,800,900。
  • 一个溢价位置都不勾 = 不加溢价：三行竞价调整全写 0，出价直接等于 CPC 基数，命名里也不带位置和溢价。
  • 活动条数 = 广告位数 × 档位数 × 投放方式数 × 竞价方案数。

组合下：

  • 一行 = 一条活动。TOS:100 ROS:50、TOS=100,ROS=50 两种写法都认；没写到的广告位按 0 处理，也不进命名。
  • 四个快捷按钮：「档位→TOS=ROS」「档位→ROS减半」「加一条不加溢价」「清空」。
  • 整段留空 = 不加溢价照样能开；想和别的组合混着开，就单独写一行 不加溢价（写 0、无 也认）。
  • 溢价超过 900% 会报错。

6.6　区块 5：命名规则

活动名 = 前缀 + 分隔符 + 勾中的后缀字段（按你排的顺序拼接）。

  • 前缀自己写，默认 全店铺_SP_Auto；分隔符默认 _。
  • 后缀字段五个，勾选启用，用 ↑↓ 调顺序：自动投放方式 / 溢价位置 / 溢价比例 / 竞价方案 / 出价。默认出价不勾，其余四个都勾。
  • 自动投放方式写法：英文（Close / Loose / Substitutes / Complements）或中文（紧密 / 宽泛 / 同类 / 关联）。
  • 最下面的「命名示例」实时显示第一条活动的完整名字，改完立刻能看到效果。
命名字段勾太少会撞名 活动名必须唯一。比如把「竞价方案」和「溢价位置」都取消勾选，几十条活动就会重名，预览区会直接报 「命名规则撞名 N 条」，并且不让生成。解决办法：把这两项勾回来，或者改前缀。

6.7　区块 6：参数与出价

参数默认说明

ROS 1.5
PP 1.5		只在「提高和降低 / DOWN UP」时生效，其余策略一律 ×1

出价怎么算

出价 = CPC 基数 ÷ ( (1 + 溢价) × 广告位系数 )
  • 例：TOS · 100% · 提高和降低 → 0.36 ÷ ((1+100%) × 2) = 0.09
  • 一条活动有多个广告位时，按最贵的那个折算，保证任何位置的落地 CPC 都不超过基数。
  • 完全不加溢价时，出价 = CPC 基数本身，不打任何系数。
  • 算出来低于 0.02 的，预览区会报「N 条出价低于亚马逊最低 0.02」并阻止生成——把 CPC 基数调高，或者去掉最高的那几个溢价档位。

参数区底部会用你当前填的数字实时演算一遍，直接看那行就行。

6.11　生成的表长什么样

只有一个工作表，名叫「商品推广活动」，表头就是亚马逊批量表的标准 27 列。每条广告活动是一「块」，块与块之间空一行：

行实体层级内容
1广告活动活动名、投放类型=自动、每日预算、开始日期、竞价方案
2–4竞价调整 ×3PP / ROS / TOS 三个广告位各一行，写各自的溢价百分比（不加溢价时全写 0）
5广告组广告组名 = 活动名，广告组默认竞价
6…商品广告 × N每个 SKU 一行
…商品定向 ×4Close / Loose / Substitutes / Complements 各一行：勾中的那种「已启用」并给折算出价，其余三种「已暂停」
…否定行否定关键词（活动级 / 组级）+ 否定商品定向（ASIN）

所以每条活动的行数 = 5 + SKU 数 + 4 + 否定行数，预览区的「每条行数」就是这个。几十条活动 × 上千个否定词，总行数上万很正常。

6.12　上传到亚马逊后台

  1. 登录亚马逊广告后台 → 「广告」→「批量操作」。
  2. 选「上传批量文件」，把下载的 xlsx 传上去。
  3. 等后台处理完，下载处理结果，逐条看有没有报错行。
  4. 确认活动已经建出来后，再回后台检查预算和竞价是否符合预期。
工具不连亚马逊后台 这个工具只负责生成文件，不会替你上传，也拿不到上传结果。上传成功与否、后台报什么错，都要在亚马逊后台看。 首次使用时建议先用一两条活动试上传，确认格式和参数没问题，再批量开。

7　完整实操示例：ES 站 301 系列自动广告

把前面三章串起来走一遍。假设你负责 ES 站，要给 HP 301 系列开一批自动广告。

准备：确认两个库

  1. 右上角站点切到 ES。
  2. 进「SKU 库」，搜 301，确认 301 相关 SKU 都在、库存是最新的。缺的先导进去（第 4 章）。
  3. 进「否定词库」，看一眼 A 类有没有要补的词；切到 D 类，确认 301 系列的墨盒和打印机在库里（欧洲 D 类由商品部在 DE 站维护，ES 站看到的是同一份）。

开广告：一个任务的完整填法

  1. 进「自动广告」，确认页头写的是「开设广告　ES 站」。
  2. 区块 1：任务名填 301系列-8月。点「从 SKU 库选」→ 搜 301 → 勾「只看有货」→ 核对列表 → 点「覆盖填入」。框里出现十几个 SKU。
  3. 区块 2：选「系列广告」→ 在型号里勾中 301 → 联动否定先保持「墨盒 + 打印机」→ 看下面三个数字，如果否定词总数过千，改成「只否墨盒型号」。
    下面五类词库保持默认（A/B/C/D 勾，E 不勾）。
  4. 区块 3：如果还有几个特别想否的机型，点「从打印机库选」→ 搜机型 → 「加哪一列」选打印机型号 → 「加到」保持「活动级 · 否定词组」→ 确认写入。注意标了「在投」的行不要勾。
  5. 区块 4：自动广告类型勾 Close；竞价方案勾 仅降低；模式选瀑布流；溢价位置点快捷键「TOS+ROS」；档位用「标准 10 档」。
    → 此时 2 个广告位 × 10 档 × 1 种投放 × 1 种竞价 = 20 条活动。
  6. 区块 5：前缀改成 ES_SP_Auto_301；后缀字段保持默认；看一眼底部「命名示例」是不是你要的样子。
  7. 区块 6：开始日期确认；每日预算按计划填；出价基数 CPC 按这个系列的目标 CPC 填（例如 0.36）；系数保持默认。

  10. 点「生成总表并下载」，拿到 批量开广告-ES-20260821.xlsx。
  11. 去亚马逊后台「广告 → 批量操作 → 上传批量文件」上传，下载处理结果检查。

9　注意事项汇总

9.1　三条最容易踩的坑

① 站点选错 自动广告和否定词库都跟着右上角的站点走。每次开始操作前先看一眼站点，尤其是负责多个站点的同事。
② 页面刷新 = 内容清空 自动广告页填的任务没有草稿保存。刷新、切站点、退出、关标签都会清空。长文本先在别处留一份。
③ 「整表替换」和「删除」不可恢复 两个库都一样，没有回收站。区域词库的整表替换还会同时影响整个区域的所有站点。操作前先「导出 Excel」留底。

9.2　数据与权限

  • 账号由超级管理员开通，不能自助注册；角色和站点自己改不了。
  • 权限改动刷新页面就生效，不用重新登录。
  • SKU 库每个账号私有；否定词库共用——A/E 按站点，B/C/D 按区域（欧洲传德国、美洲传美国）。
  • 词库每行都记添加人和添加时间，改动可追溯，也请对自己加的词负责。
  • 登录状态保持 12 小时；公用电脑用完请退出。

9.4　浏览器与环境

  • 用 Chrome / Edge 最新版；不要用 IE。
  • 只能在公司内网访问，地址是 http:// 不是 https://。
  • 页面显示不全时把浏览器缩放调到 80–90%（自动广告是三列布局，屏幕窄会挤）。
  • 生成的 xlsx 走浏览器下载，注意别被拦截；下载目录按浏览器设置。
  • 大批量操作（几千行导入、上万行生成）时页面可能卡顿几秒，不要重复点按钮。
