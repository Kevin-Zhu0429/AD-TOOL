# CYES 广告工作台

## Overview

中文界面的广告运营工具，处理多站点、多语言搜索词。设计参照现有广告优化工作台及搜索词明细：优先让用户逐行核对投放系列、搜索需求和数据指标。此次工作只调整检测结果和解释，保留既有视觉身份。

## Colors

运行时源为 `web/src/index.css`。`web/src/components/optimizer.css` 的 Shadow DOM 适配层将 `--red/--red-soft` 映射为 `--mg/--mg-b`，将 `--amber/--amber-soft` 映射为 `--ye/--ye-b`。红色表示疑似跑偏，黄色表示需要核对；必须同时有文字标签，不单靠颜色。

## Typography

沿用 `--font` 的 Segoe UI、苹方、微软雅黑等回退字体；数字指标沿用 `--mono` 与等宽数字。机型和墨盒列表保留原始可读写法。长原因允许换行，不能只通过鼠标悬停读取。

## Layout

首页功能入口试用圆形轮播（2026-10-13，用户指定 React Bits CircularCarousel）：`HomePage` 维护入口数据与原权限条件，`CircularCarousel` 维护弯曲卡片、三维环绕、拖动惯性及选中状态。功能卡片使用本地 HTML 和现有 `Icon`，颜色沿用 `index.css` 的语义变量，不引入外部图片或动效依赖。轮播下方持续显示选中功能的完整说明、进入按钮和全部可用功能的选择按钮；两侧卡片先聚焦，正中卡片点击进入。手机保留正中卡片可读尺寸，侧面允许在轮播内部裁切；页面沿用 `AppShell` 的滚动区域。首页云层页头、主导航和更新日志继续使用现有组件。

手动广告投放方式为三段：关键词投放、关键词三合一（一个粘贴框 + 三种匹配各自的开关与出价，窄屏改为纵向）、商品投放。手动广告的活动标签独立横向滚动，右侧新增与复制按钮保持可见，窄屏操作条换行。投放词清空及撤销沿用既有按钮与内联文字反馈，保持原表单密度及页面滚动。

ABA 明细采用更紧凑的 8px 行内纵向间距和 650–1050px 的表格滚动区。机型汇总行使用现有 `--panel-2` 背景与品牌色展开按钮，下方展开搜索词，保留截图参考中的“机型 → 搜索词”关系。专注明细收起表格之前的非必要区域，仍保留搜索和类型切换，不改变全站页面滚动。

保留原生表格、左侧活动导航和分析页结构。原因列随内容增高，保留指标列及否定操作；`.antbl .drift-reason` 的最小宽度为 260px、最大宽度为 380px，避免窄屏把长原因压成逐字竖排。窄屏沿用工作台内容滚动，不为新标签改变页面滚动所有权。

## Elevation & Depth

浅色卡片动效增强（2026-10-13）：用户认可深色效果，深色配色、透明度与遮罩保持原样。浅色背景透明度提高到 0.96，轻微提升饱和度；极光使用完整色彩渲染，波浪从浅色主题的 `--violet` 与 `--accent` 派生更深的波体与浅紫浪峰。图标上方与中段保留更明显的颜色，正文起始处快速减弱至 12% 遮罩，维持深色标题和说明文字的可读性，不修改圆环布局或交互。

首页圆形卡片背景动效（2026-10-13，用户提供源码后更新）：使用用户指定的 Gradient Shader Card、Aurora、GradientWaves 三个真实 Shader，着色器源码由 `cardShaderSources.js` 保留，`cardShaderRenderer.js` 适配为一个共享 WebGL2 上下文和时钟；不依赖各组件原来的 React Three Fiber 或 OGL 包装层。手动广告、SKU 库、产品情报与小工具用原始颗粒渐变，自动广告、否定词库、组合库与账号管理用极光，ABA、广告优化与超龄费用用波浪。Shader 保留原始配色与噪声/波浪算法；主题遮罩、图标底、边框与正文仍读取 `index.css` 的语义变量。每种效果每帧只渲染一次，并通过 2D Canvas 将同一帧的对应切片贴到弯曲卡片正面；背面使用静态装饰。桌面纹理为 256px 宽、最多 24 帧/秒，手机为 144px 宽、最多 20 帧/秒并降低波浪步数。动效集中在上半部并向正文渐隐；暂停、后排、离开可视区域或浏览器后台时停止更新，减少动态效果时绘制静态 Shader。WebGL2 不可用或上下文丢失时显示静态主题渐变。

2026-10-09 起全站使用一层统一的“质感层”变量，定义在 `web/src/index.css` 的主题块内，组件只引用变量、不写死颜色：

- `--hairline`：卡片顶部 1px 内高光；`.card`、`.sec`、`.bhero`、`.kpi`、首页入口卡共用。
- `--glass`：顶栏、吸顶操作条和用户菜单的半透明底，配合 `backdrop-filter` 模糊。
- `--grad-brand` / `--grad-line`：主按钮、编号徽标、选中分段控件描边、顶栏底线与页头流光线。
- `--glow`：主按钮悬停与品牌徽标的主色辉光；`--ambient-1/2` 为页面背景固定的两团环境光。
- 正在填写的 `.sec` 以主色描边和 4px 柔光标出（`:focus-within`），不改变布局尺寸。

常规动效用于入场与悬停：页面切换整体淡入，三列卡片依次浮上，入场动画只用 `backwards` 填充，不锁住悬停位移。首页功能轮播是用户指定的持续动效例外：缓慢转动，悬停及键盘聚焦暂停，提供明确的暂停按钮；离开可视区域或切换浏览器标签页时停止绘制。`prefers-reduced-motion` 时关闭自动转动与入场效果，按钮和方向键切换直接落到选中位置。

## Shapes

状态标签复用 `.flagchip`，表格行复用 `.lv-bad` 和 `.lv-warn`。

## Components

AI 连接授权页由 `server/src/mcpAuth.js` 的 `loginPage` 维护。独立登录页读取 `/mcp-auth.css`，其源文件仍是 `web/src/index.css`，字体、主题、边框和反馈色沿用网站语义变量。授权能力列表明确区分只读与读写；错误内联显示并保留用户名，不回填密码。密码显隐使用原生按钮，提交时保持按钮宽度并禁用重复提交，窄屏维持单栏自然滚动。验证入口为 `web/tests/mcp.browser.mjs`。

操作日志继续放在账号管理内，使用现有紧凑表格和原生筛选器。顶部以一条浅品牌色“账本摘要”同时展示近 7 天与近 30 天总数，下面的账号统计和事件明细保持扁平、可扫描；动作和对象转换为业务中文，不直接把内部枚举或整段 JSON 当作主要内容。窄屏时摘要与筛选器纵向排列，表格自身承担横向滚动。

摸鱼率按用户确认的次数口径显示在近 7 天、近 30 天计数后，顶部汇总和各账号行使用同一 `AuditRate` 呈现百分比及分子/分母。公式为登录、打开板块、退出登录次数除以同期总次数；无操作显示“—”，不设置评价阈值或风险配色。概要文字说明统计范围，窄屏摘要按两列分组，账号表维持内部横向滚动。

船长库存沿用 SKU 库与账号管理的紧凑后台语言，不新增独立视觉系统。SKU 库左栏使用一张同步卡，
明确写出欧洲共享范围、绑定品牌和同步结果；主操作复用 `.btn.primary`，异步期间保持按钮尺寸稳定。

库存风险联动以“当前在库能否继续承接广告点击”为唯一高亮依据：库存接口明确返回在库为 0 时，SKU 库与广告优化 SKU 矩阵都使用现有红色危险语义、文字标签和表格左侧状态线；空白库存不当作 0。有在途库存时仍显示“在库 0”，并在次级文字中保留在途数量。SKU 矩阵顶部用一条持久页内风险摘要展示受影响项数、周期点击与花费，筛选按钮可只看零库存项；不自动暂停广告，不以颜色替代文字，也不新增独立色值或浮动通知。

超级管理员的店铺绑定位于账号管理的独立页签，按船长库存页面的逻辑店铺分组；先选择组级 SKU 品牌，
再按国家分别选择负责人，账号与品牌均使用原生选择器。品牌默认取逻辑店铺名中的品牌前缀，并补充组内任一国家已有的 SKU 品牌；负责人选项再按“国家 + 品牌”过滤。允许只保存已有 SKU 的国家，其余选择器保持空白并给出明确原因。绑定与当前状态继续使用两张紧凑表格；读取、
空状态、未配置、部分失败与成功均使用现有持久内联 `.note`，错误和店铺状态不只依赖颜色。

广告组合库复用 SKU 库的两栏导入与紧凑原生表格语言。组合名称旁显示从真实名称解析出的“540 Series”“混投”或“不参与自动匹配”文字标签，分类不只依赖颜色。自动和手动广告共用 `PortfolioField`：原生选择器接受操作系统弹出层，状态文字稳定放在控件下方；自动匹配成功用绿色文本，资料或映射缺失用黄色文字提示，手动选择保留当前表单密度。广告组合页面不新增全局色值、圆角或阴影。

ASIN 筛选控件按墨盒型号、品牌、ASIN、SKU 排列，型号与品牌分开选择；多周统计沿用原生选择器切换合计和周平均。平均明细显示实际出现周数，缺失关联提供可展开 ASIN 清单，保持现有紧凑表格和窄屏换行。

ABA ASIN 视图复用品牌视图的上传组件 `AbaReportUpload`、分页组件 `AbaPagination`、原生筛选控件和表格滚动样式。表格先放机型识别和搜索查询，随后并排对照市场与 ASIN 指标；搜索词下方保留 ASIN、关联 SKU 和实际周清单，便于核对数据归属。默认不同 ASIN 独立成行；选择墨盒型号后合并颜色套组，显示来源 ASIN 清单。市场冲突以文字提示和可展开来源值解释，空值使用「—」。窄屏只在表格内横向滚动。

ASIN 明细与机型分类共用 `AbaAsinTable`。分类沿用品牌视图的浅底汇总行、展开按钮和嵌套分页，首列同时显示机型与 ASIN，墨盒 KW 词作为明确分类显示。上传区兼容 CSV 和合并 XLSX，多个报告的预览折叠展开，不让一份大合并表挤占整个页面。

ASIN 两种显示方式均在结果标题右侧提供同一「导出 Excel」按钮，词类型筛选不限制入口；没有匹配结果时禁用。明细导出一条显示记录一行，数量保持当前合计、逐周或周平均口径，来源 ASIN、SKU、报告周和市场冲突作为核对信息；分类汇总继续沿用原有拆分格式。私有与公共页面共用组件和格式生成器，导出读取当前全部筛选结果，切换筛选或离开页面会取消过期导出。

ABA 品牌视图沿用 `index.css` 的 `--panel`、`--border`、`--accent`、`--text-dim` 与字体变量，由 `AbaPage.css` 负责布局适配。主要视觉是按周排列的等尺度条形图、市场与品牌六项数量总览，以及与 ASIN 视图对齐的 11 列明细表。日期与周数放在搜索词下方；品牌指标缺失时提供重新上传提示。报告筛选控件使用原生选择器与复选框；只有表格自身承担横向和固定高度滚动，不改变页面滚动。中文运营界面服务 ES 等市场，无日本本地化范围。

超龄仓储费使用独立顶层页面和近全宽容器，保留主导航与页面滚动；宽数据表自行承担横向及限高滚动。市场费率以可展开矩阵呈现，列标题写明库龄阶段，单位直接标为美元/件/次。筛选与排序沿用全站原生选择器，导入和修正沿用工作台按钮、提示与语义颜色。

`modelDrift.js` 的 `driftPresentation` 定义结果名称和语义色，`optApp.js` 的 `driftBadge` 负责统一渲染。明细与分析页不得各自解释状态。检测行为和验证入口见 `UX-CONTRACT.md`。

公共 ABA 复用 `AbaAsinView`、`AbaAsinTable` 和 `AbaPagination`，通过明确的公共变体关闭上传并使用共享查询。国家切换位于内容顶部，使用带中文国家名与站点码的整行大按钮，选中状态同时体现底色、底部强调线与 aria-pressed。同步采用持久页内状态区、真实批次进度及可分页的任务表；字体、颜色、圆角来自 `index.css` 的既有变量，页面自然滚动，任务与报告表各自承担横向滚动。

超级管理员登录后的待处理区由 `AdminAttention` 在应用内容顶部统一维护，所有页面持续可见。自动补拉仍失败时使用既有琥珀色语义边框、数量与明确原因显示需要处理的报告，默认预览三项，展开后复用 `AbaPagination` 分页；提供前往公共 ABA 和刷新入口。读取失败保留上次列表并注明状态，查看不清除事项；窄屏以单列自然换行，不新增独立通知颜色或临时弹窗。

## Do's and Don'ts

- 显示候选机型、对应墨盒以及活动是否已投放，让人工判断有具体依据。
- 保留输入搜索词，不把推测的机型写成用户明确输入的机型。
- 装饰与动效沿用上面的质感层变量和入场 / 悬停动画，首页圆形轮播按用户指定的试用例外实现；不为单个页面另起视觉系统，不写不影响决策的实现说明。
- 不将词库记录冲突或 SKU 资料缺失显示为确定的未投放。
